왜 좋을까요?

코딩이 필요 없어요복사해서 붙여 넣으면 돼요.
프로그램은 무료예요누구나 쓸 수 있어요. Codex 사용 조건은 내 ChatGPT 요금제를 따라요.
글자 넘침을 검사해요Codex가 넘친 글자를 찾아 고칠 수 있어요.
내 컴퓨터에 저장돼요슬라이드가 인터넷에 저절로 올라가지 않아요.

    ⬇ ZIP 바로 받기
  3. 압축을 풀어요

    slide-wizard-main 폴더를 문서 폴더로 옮겨요.

사용하는 법

이렇게 써요

  1. Codex에서 폴더를 열어요

    ChatGPT 앱에서 Codex를 고르고 slide-wizard-main 폴더를 열어요. 이 단계가 제일 중요해요.

  2. 마법사를 켜요
    슬라이드 마법사 켜줘. 나는 코딩을 몰라서 쉽게 설명해 줘.

    “실행해도 될까요?”라고 물으면 설명을 읽고 허용해요. Codex가 알려 주는 주소를 누르면 돼요.

  3. 슬라이드를 부탁해요

    빨간 부분만 내 이야기로 바꿔요.

    슬라이드 만들어줘. 듣는 사람: 우리 반 친구들 하고 싶은 이야기: 재활용을 제대로 하는 법 느낌: 밝고 재미있게 장수: 10장

    화면의 ✦ AI로 만들기 버튼으로도 만들 수 있어요.

  4. 고치고 발표해요

    글자는 클릭해서 고쳐요. 큰 수정은 Codex에게 말해요.

    재활용 슬라이드의 5번 장을 표로 바꾸고, 다 고치면 넘친 글자가 없는지 검사해줘.

    ▶ 발표를 누르고 방향키로 넘겨요. PDF를 누르면 파일로 저장할 수 있어요.

Codex에게 적은 글과 자료는 AI가 읽도록 OpenAI로 전달돼요. 비밀번호와 개인정보는 넣지 마세요.
막히면 화면에 나온 말을 그대로 Codex에게 붙여 넣고 “고쳐줘”라고 해 보세요.
